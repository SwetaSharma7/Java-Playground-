# Java Playground

Core Java, Java programs and DSA practice in Java, aimed at SDET interviews.

## Structure

| Folder | What's inside |
|---|---|
| `src/oop` | OOP concepts: encapsulation, polymorphism, method overriding, static, 2D arrays |
| `src/javaprograms` | Classic Java interview programs written without built-in shortcuts, plus a Java 8 streams set |
| `src/leetcode` | Accepted LeetCode solutions, grouped by topic |

## Topics

- **Java programs:** strings, arrays, number problems, sorting, pattern printing, streams
- **LeetCode:** arrays, strings, hashing, two pointers / sliding window, stack, linked list, binary search, math & matrix, trees, recursion & DP
